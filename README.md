## ✨ Overview

<div align="center">

<table>
<tr>
<td width="65%">

**Campus Suite** is a next-generation student management platform engineered for educational institutions. Built with cutting-edge React architecture and Tailwind CSS, it delivers exceptional performance while providing an intuitive interface for managing students, tracking attendance, processing fees, and organizing classes — all in one unified ecosystem.

</td>
<td width="35%">

```
⚡ Stack: React 18 + Vite
🎨 Styling: Tailwind CSS
📦 State: React Hooks
💾 Storage: LocalStorage
🌐 Deploy: GitHub Pages
🎯 Focus: UX & Performance
```

</td>
</tr>
</table>

|:-----|:----------|:------------:|

| `/students/add` | Add Student | 🔒 Authenticated |

## ⚡ Quick Start Guide

```bash
# Clone the repository
git clone https://github.com/amritghumanofficial/campus-suite.git

# Navigate to project directory
cd campus-suite

# Install dependencies
npm install

# Start development server
npm run dev

# Application will be available at http://localhost:5173
```
